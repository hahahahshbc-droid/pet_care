# 毛里时光 · 宠物洗护

使用 Next.js App Router、React 和 TypeScript 构建的宠物洗护单页，生产构建会静态导出到 `out` 目录。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

店名与价格为演示内容，预约表单仅生成页面内意向，不提交、不存储用户数据。上线经营前请替换店名、价目、地址、营业时间并接入真实预约渠道。
