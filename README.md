# 毛里时光 · 宠物洗护单页

直接用浏览器打开 index.html。样式、交互和图片均内嵌，无需安装依赖或联网。

店名与价格为演示内容，预约表单仅生成页面内意向，不提交、不存储用户数据。上线经营前请替换店名、价目、地址、营业时间并接入真实预约渠道。

dist/index.html 是相同页面的托管副本，修改后请同步。
